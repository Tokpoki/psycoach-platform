
# 7. Техническая структура

| Компонент | Функция |
|------------|----------|
| **Frontend (игра)** | Android — визуализация эмоций и сцен |
| **Backend (логика)** | Node.js / Python (FastAPI) — управление сценариями и прогрессом |
| **База данных** | PostgreSQL / Firebase — хранение пользователей и достижений |
| **AI-модуль** | Генерация эмоций спортсменов через AI (Stable Diffusion / Unreal MetaHuman) |
| **Панель администратора** | Добавление курсов, обновление контента, статистика пользователей |


# 8. Минимально жизнеспособный продукт (MVP)

- Регистрация и выбор роли (спортсмен, тренер, родитель).
- 1–2 базовых сценария с выбором реакции и обратной связью.
- Простая визуализация эмоций (2D или AI-рендер персонажей).
- Подсчёт очков и вывод уровня прогресса.
- Тестовый курс: «Как справиться с волнением перед стартом».

# 9. Запуск backend

```bash
docker compose up
```

# 10. Миграции БД

Для работы с миграциями используется Alembic. Основные команды:

```bash
# создание новой миграции на основе текущих моделей
alembic revision --autogenerate -m "init"

# применение всех миграций
alembic upgrade head

# откат на одну версию при необходимости
alembic downgrade -1
```

# 11. Демо-данные

Для наполнения базы примерами сценариев и курсов выполните сиды:

```bash
docker compose run --rm seed
# или
make seed
```

После применения сидов доступен тестовый администратор `admin@local` с паролем `admin`.

# 12. Проверки и качество кода

## 12.1. Установка зависимостей для разработки

```bash
pip install -r requirements.txt
```

## 12.2. Запуск тестов и измерение покрытия

```bash
pytest
```

Команда включает подсчёт покрытия (`pytest --cov`) и должна поддерживаться на уровне не ниже 80%.

## 12.3. Линтеры и статический анализ

```bash
ruff check
black --check .
isort --check-only .
mypy --config-file mypy.ini backend/app
```

## 12.4. Pre-commit хуки

```bash
pre-commit install
pre-commit run --all-files
```

Хуки запускают форматирование, линтеры и mypy перед коммитами.

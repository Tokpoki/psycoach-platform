# 1. Цель проекта

Создать интерактивное приложение по спортивной психологии, объединяющее:

- спортсменов, тренеров и родителей,
- психологические тренировки в формате игры,
- продажу курсов по эмоциональной регуляции, мотивации и стрессоустойчивости.

Приложение помогает развивать навыки:

- контроля эмоций,
- концентрации,
- уверенности,
- восстановления после поражений.


# 2. Концепция проекта

**Формат:** онлайн-игра с элементами психологической тренировки.  
**Цель игрока:** прокачивать психические навыки через прохождение ситуаций, выбор реакций и мини-игры.


# 3. Основные роли пользователей

| Роль | Цель использования | Тип контента |
|------|---------------------|--------------|
| **Спортсмен** | Учится управлять эмоциями, справляться с волнением, страхом, поражениями | Интерактивные ситуации, дыхательные упражнения, визуализация |
| **Тренер** | Получает советы по коммуникации, мотивации и восстановлению спортсменов | Тесты, сценарии общения, симуляции командных ситуаций |
| **Родитель** | Понимает, как поддерживать ребёнка, не давить и не усиливать тревогу | Вопросники, подсказки поведения, видео-пояснения |
| **Психолог** | Даёт рекомендации и анализирует результаты | Аналитика, обратная связь, чаты |
| **Администратор / Разработчик курсов** | Создаёт новые игровые сценарии и курсы | Панель редактирования контента |


# 4. Игровая структура

## 4.1. Аватар спортсмена
Пользователь создаёт персонажа (спортсмена, тренера, родителя).  
Аватар растёт и развивается при успешных прохождениях заданий.  
Возможность выбрать вид спорта (хоккей, дзюдо, гимнастика, карате и др.).  
У спортсменов отображаются эмоции: радость, печаль, страх, гнев, удивление, отвращение.

## 4.2. Сценарии из спорта
Примеры ситуаций:
- перед стартом (волнение, тревога),
- после поражения (разочарование, злость),
- конфликт с тренером или партнёром,
- несправедливость судейства,
- восстановление после травмы.

Игрок выбирает реакцию из трёх вариантов, получает баллы и объяснение, почему это решение эффективно психологически.

## 4.3. Мини-игры
- **Фокус и концентрация:** следи за объектом, дыхательные ритмы.  
- **Визуализация:** представь и собери последовательность действий.  
- **Стресс-тесты:** задачи на время при шуме и отвлекающих факторах.  
- **Эмоциональная регуляция:** дыхание 4–4–6, позитивные установки.

## 4.4. Система прогресса
Очки, уровни, медали, статусы («Мастер концентрации», «Капитан спокойствия»).  
Достижения открывают новые сценарии или мини-игры.

## 4.5. Обратная связь
После каждого выбора — объяснение, какой психологический навык применён  
(например, «дыхательная техника уменьшает тревогу»).


# 5. Психологическая карта (визуальная модель)

Изображения показывают эмоциональный путь спортсмена.

| Этап | Эмоции / состояния | Психологические задачи |
|------|---------------------|-------------------------|
| 1. Родители, тренер, соперники | Страх, тревога, стресс | Формирование поддержки и уверенности |
| 2. Ошибки, поражения, травмы | Гнев, обида, стыд | Работа с самопринятием |
| 3. Сомнения, сравнение | Вина, агрессия | Развитие ответственности и принятия |
| 4. Радость, мотивация, забота | Уверенность, любовь | Формирование позитивного мышления |
| 5. Творчество, духовность, дружба | Отдых, здоровье | Баланс и саморазвитие |


# 6. Контентная база (курсы и направления)

Каждый курс — это интерактивная цепочка уроков + игра.

Примеры курсов:
- «Предстартовое волнение» — дыхание, визуализация, самонастрой.  
- «Поражение без выгорания» — техника восстановления уверенности.  
- «Работа с критикой тренера» — ассертивное мышление.  
- «Мотивация и фокус» — упражнения на внимание.  
- «Родитель без давления» — советы по поддержке ребёнка.


# 7. Техническая структура

| Компонент | Функция |
|------------|----------|
| **Frontend (игра)** | Android — визуализация эмоций и сцен |
| **Backend (логика)** | Node.js / Python (FastAPI) — управление сценариями и прогрессом |
| **База данных** | PostgreSQL / Firebase — хранение пользователей и достижений |
| **AI-модуль** | Генерация эмоций спортсменов через AI (Stable Diffusion / Unreal MetaHuman) |
| **Панель администратора** | Добавление курсов, обновление контента, статистика пользователей |


# 8. Минимально жизнеспособный продукт (MVP)

- Регистрация и выбор роли (спортсмен, тренер, родитель).  
- 1–2 базовых сценария с выбором реакции и обратной связью.  
- Простая визуализация эмоций (2D или AI-рендер персонажей).  
- Подсчёт очков и вывод уровня прогресса.  
- Тестовый курс: «Как справиться с волнением перед стартом».

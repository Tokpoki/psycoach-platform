# TECHNICAL_SPECIFICATION: PsyCoach
Дата: 2025-11-01 07:00:47 UTC

> Этот документ описывает MVP-версию игрового приложения по спортивной психологии для спортсменов, тренеров, родителей и психологов. Вся спецификация собрана в одном файле. Иллюстрации находятся в каталоге `docs/assets/` и используются как визуальные референсы.

---

## 1. Цели и границы MVP
### 1.1. Бизнес-цель
- Дать пользователям практические инструменты по управлению эмоциями и вниманием через короткие сценарии и мини‑игры.
- Формат — **продаваемые интерактивные курсы** с прогрессией: уровни, очки, бейджи.

### 1.2. Научно‑психологическая рамка
- Базовые эмоции: радость, печаль, страх, гнев, удивление, отвращение. Визуально выражаются аватаром и в текстовых объяснениях.
- Навыки: концентрация, визуализация, эмоциональная регуляция, стрессоустойчивость, саморазговор, переключение внимания.

### 1.3. Зона ответственности MVP
- **Есть**: регистрация, роли, прогресс, мини‑игры, сценарии как текстовые карточки с выбором.
- **Нет**: полноценный маркетплейс курсов, чат с психологом, офлайн‑синхронизация, платежи.

---

## 2. Роли и пользовательские запросы
### 2.1. Спортсмен
- Предстартовое волнение, уверенность, мотивация, концентрация, поражения, восстановление после травмы, отношения с тренером/командой, баланс со школой/жизнью.

### 2.2. Родитель
- Высокие ожидания, сравнение, тревога, поддержка, финансы, учеба vs спорт, признание.

### 2.3. Тренер
- Работа с командой и лидерами, конфликтные спортсмены, правильный разговор после поражений, собственная мотивация и выгорание, взаимодействие с родителями, построение психологии на сезон.

### 2.4. Судья
- Давление, нейтральность, концентрация, эмоциональная устойчивость, общение и лидерство.

## 4. Гейм-дизайн и прогрессия
### 4.1. Очки и уровни
- Базовая шкала: `Level = max(1, floor(points / 100) + 1)`.
- Бейджи: «Мастер концентрации» за суммарный счёт в мини‑играх > 300; далее — «Капитан спокойствия», «Железные нервы», «Фокус‑профи» (пороговые значения конфигурируемы).

### 4.2. Сценарии
- Каждый сценарий — короткая ситуация из спорта с выбором реакции.
- Выбор даёт `score_delta` и **объяснение** действия: почему оно психологически верно.
- Сценарии фильтруются по роли и тематике.

### 4.3. Мини‑игры
1) **Фокус и концентрация**: удержание внимания, дыхательные ритмы.
2) **Визуализация**: выстраивание правильной последовательности действий и образов.
3) **Стресс‑тест**: таймер, скорость принятия решения под «давлением».
4) **Эмоциональная регуляция**: дыхание 4‑4‑6, позитивный саморазговор, переключение фокуса.

### 4.4. Анти‑чит и контроль сложности
- Ограничение частоты отправки результатов, серверные валидации диапазонов очков.
- Адаптация сложности по EMA (простая эвристика): если игрок трижды подряд превышает порог, поднимать сложность на +1, если трижды не дотягивает — снижать на −1.

## 5. Контентная модель
### 5.1. Базовые эмоции и навыки
| Эмоция | Навык‑мишень | Примеры мини‑игр |
|---|---|---|
| Страх | Регуляция, дыхание | Дыхание 4‑4‑6, когнитивная переоценка |
| Гнев | Переключение внимания | Счёт по шаблону, отсев отвлекающих стимулов |
| Печаль | Самоподдержка | Журнал маленьких побед |
| Радость | Удержание фокуса | Ритм‑таппинг без срывов |
| Удивление | Переключение | Быстрая сортировка стимулов |
| Отвращение | Десенсибилизация | Короткие экспозиции с дыханием |

### 5.2. Тематические группы сценариев
- Родители, Тренер, Соперник, Напарник, Команда, Поражение, Ошибки, Травма, Принятие, Ответственность, Мотивация и т.д.

## 6. Форматы данных для сидов
### 6.1. Сценарий (JSON)
```json
{
  "title": "Предстартовое волнение",
  "kind": "PRESTART",
  "role_scope": "athlete",
  "content_json": {
    "summary": "Мысли о возможной ошибке мешают.",
    "prompt": "Что ты делаешь прямо сейчас?"
  },
  "choices": [
    {
      "text": "Думаю о соперниках",
      "explanation": "Сравнения усиливают тревогу и уводят фокус.",
      "skill_tags": ["переключение_внимания"],
      "score_delta": -2
    },
    {
      "text": "Делаю 3 цикла дыхания 4-4-6 и представляю старт",
      "explanation": "Дыхание снижает физиологическое возбуждение, визуализация выравнивает фокус.",
      "skill_tags": ["дыхание", "визуализация"],
      "score_delta": 3
    },
    {
      "text": "Пишу другу, чтобы отвлечься",
      "explanation": "Отвлечение не формирует навык регуляции.",
      "skill_tags": ["саморегуляция"],
      "score_delta": -1
    }
  ]
}
```

### 6.2. Мини‑игровой результат (JSON, клиент → сервер)
```json
{
  "score": 120,
  "metadata": {"difficulty": 2, "streak": 4, "duration_sec": 90}
}
```

## 7. API‑контракты (совместимо с текущим backend)
- Health‑проверки: `GET /ping`, `GET /healthz`, `GET /readyz`.
- Сценарии:  
  - `GET /scenarios?role=...&kind=...` — список.  
  - `GET /scenarios/{id}` — сценарий с вариантами.  
  - `POST /scenarios` — создание (роль ADMIN).  
  - `POST /scenarios/{id}/choice` — применить выбор и получить результат.
- Мини‑игры:  
  - `POST /minigames/{type}/result` — сохранить результат и обновить прогресс.

### 7.1. Примеры
**POST /scenarios/{id}/choice → 200**
```json
{
  "applied_skill": ["дыхание"],
  "explanation": "Дыхание снижает физиологическое возбуждение...",
  "new_points": 240,
  "new_level": 3,
  "new_badges": ["Level 3 achiever"]
}
```

**POST /minigames/FOCUS/result → 201**
```json
{
  "result": {"id": 12, "type": "FOCUS", "score": 120, "created_at": "..."},
  "progress": {"points": 360, "level": 4, "badges": ["Мастер концентрации"]}
}
```

## 8. Модель данных (ORM‑уровень)
- `User(id, email, password_hash, role)`
- `Scenario(id, title, kind, role_scope, content_json, choices=[])`
- `Choice(id, scenario_id, text, explanation, skill_tags[], score_delta)`
- `Progress(user_id, points, level, badges[])`
- `MiniGameResult(id, user_id, type, score, created_at)`

---

## 9. Алгоритмы начисления очков и уровней
### 9.1. Сценарии
- Применение варианта → `Progress.points += score_delta` с нижней границей 0.

### 9.2. Мини‑игры
- `points += score`, где `score` ограничен сервером в допустимом диапазоне `[0, 300]` по типу игры.
- При сумме очков по всем мини‑играм > 300 → бейдж «Мастер концентрации».

## 10. UI‑потоки (Android MVP)
1) Onboarding + регистрация → выбор роли.  
2) Главный экран: «Сценарии» и «Мини‑игры».  
3) Сценарий: карточка ситуации → выбор → результат с объяснением.  
4) Мини‑игра: старт → результат → прогресс.  
5) Профиль: уровень, очки, бейджи.

## 11. Нефункциональные требования
- **Локализация**: RU, EN.  
- **Аксессибилити**: контраст, крупные кликабельные области, поддержка screen‑reader.
